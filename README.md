# JSKY Weekly Crew Planner

GitHub Pages deployment package.

## Deployment
Upload the contents of this folder to the repository root:
- `index.html`
- `jsky_brand_logo.jpg`

Then enable GitHub Pages for the repository/branch if it is not already enabled.
